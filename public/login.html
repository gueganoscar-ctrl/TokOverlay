Comment obtenir votre clé API

💡 Bon à savoir : TokOverlay utilise le service API gratuit EulerStream pour récupérer le flux TikTok en direct.
  1. Rendez-vous sur le site eulerstream.com.
  2. Créez un compte gratuitement.
  3. Rendez-vous sur eulerstream.com/dashboard.
  4. Créez votre première clé API.
  5. Copiez la clé générée et collez-la ci-dessus.
