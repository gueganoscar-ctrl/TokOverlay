Comment obtenir votre clé API

💡 Bon à savoir : Si TokOverlay est 100% gratuit, c'est grâce à ce service de connexion API qui est entièrement gratuit !
  1. Rendez-vous sur le site www.eulerstream.com.
  2. Cliquez sur le bouton pour obtenir une clé API.
  3. Créez votre compte gratuitement.
  4. Créez votre clé API.
  5. Copiez la clé API générée et collez-la dans le formulaire d'inscription TokOverlay.
